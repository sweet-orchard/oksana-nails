# oksana-nails

Editorial nail studio website for **Oksana** — BIAB & natural nail aesthetics based in Bristol, UK.

## Structure
- `index.html`: Standalone, mobile-first editorial magazine layout (HTML5 + Tailwind CSS)
- `images/`: High-resolution imagery and assets
- `base44-oksana project/`: Modular React + Vite + Tailwind CSS application
